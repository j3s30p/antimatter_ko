# Antimatter Dimensions Steam 한국어 패치

Antimatter Dimensions Steam 11.5용 한국어 번역 프로젝트입니다. 현재는 개발 중이며, 완성된 배포본이 아닙니다.

## 현재 상태

- 초반 Modern UI 시험 번역
- Galmuri9 Regular 적용
- 번역 범위 및 용어집 확정
- Steam 빌드와 실제 실행 검증 완료

번역 범위는 `docs/TRANSLATION_SCOPE.md`, 고정 용어는 `docs/GLOSSARY.md`에서 관리합니다.

## 주의

- Automator 명령어는 호환성을 위해 영어를 유지합니다.
- Steam 업데이트나 파일 무결성 검사는 패치를 제거할 수 있습니다.
- Steam 오버레이의 업적 명칭은 로컬 패치 범위 밖입니다.
- 배포판 설치 도구가 완성되기 전에는 저장소의 개발 파일을 직접 설치하지 마세요.
