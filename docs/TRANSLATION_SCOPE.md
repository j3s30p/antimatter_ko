# Korean localization scope

This patch targets the Steam build of Antimatter Dimensions version 11.5.

## Included

- All player-facing Vue UI text, including tabs, buttons, tooltips, modals, options, statistics, and notifications
- Gameplay names and descriptions for upgrades, challenges, achievements, studies, Glyphs, Celestials, and progression systems
- How-to-play documentation, tutorials, catch-up text, and story dialogue
- Automator documentation and error messages
- News ticker and changelog, translated after core gameplay reaches full coverage
- Discord Rich Presence text generated by the game where practical
- Galmuri9 Regular for the main UI, bundled with its SIL OFL 1.1 license

## Preserved in English

- Automator command keywords and grammar
- Save-data keys, internal identifiers, API fields, URLs, and file paths
- Player-entered Automator scripts
- Personal names in credits
- Standard abbreviations such as AD, AM, IP, EP, RM, and TT after their Korean meaning is established
- Steam achievement metadata controlled by Steam rather than the local game bundle

## Delivery order

1. Shared terminology, navigation, currencies, common controls, and early game
2. Infinity and Eternity progression
3. Dilation, Reality, Glyphs, and Automator documentation
4. Celestials, story dialogue, endgame, and completion flow
5. Help pages, achievements, statistics, options, and remaining modal/error text
6. News ticker and changelog
7. Full English-residue audit, layout QA, clean-install test, and release packaging

## Definition of done

- No unintended player-facing English remains in supported gameplay screens
- Dynamic placeholders, HTML, Vue bindings, and formatting calls are preserved
- Automator syntax and save compatibility are unchanged
- All translated screens are checked for clipping at common UI scales
- A clean Steam install can be patched and restored without touching save data
- The release contains installation, restoration, license, version, and checksum information
